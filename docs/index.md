# Tarea #2 de Física computacional de Kevin Mauricio Chacón Ureña 

Éste sitio contiene la documentación del código utilizado para resolver la integral $I$ mediante el método numérico de **Cuadratura Gaussiana**.

$$I=\int_0^{\pi} \sin(x^2) dx$$

Ésta integral es de especial interés porque no tiene una solución analítica, por lo que solo se puede resolver mediante métodos numéricos.
